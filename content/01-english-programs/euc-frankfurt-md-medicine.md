# EUC Франкфурт — Doctor of Medicine (European University Cyprus, Frankfurt Branch)

[[index]] · [[01-english-programs/|01 — Англоязычные программы]]

Филиал **School of Medicine** частного **European University Cyprus** (EUC) во Франкфурте-на-Майне. Программа **MD (Doctor of Medicine)**, 360 ECTS, 6 лет — полностью **на английском**; клинические ротации в Германии. Аккредитация WFME; диплом кипрского вуза с обучением на кампусе в DE. **Не** государственный немецкий Humanmedizin / Staatsexamen.

## Структурированная выжимка

| Параметр | Значение |

| **Язык обучения** | **Английский** (немецкий — для клинической интеграции, постепенно) |

| **Начало** | Осенний семестр (сентябрь/октябрь) |

### Требования к поступлению

- Аттестат средней школы (high school leaving certificate).
- **Английский обязателен** для Frankfurt Campus (даже для носителей — по правилам EUC для визы): IELTS Academic **≥ 6.5**, TOEFL iBT **≥ 79**, PTE **≥ 66** или эквивалент CEFR B2+ (полный перечень — на сайте EUC).
- **Нет** классического Numerus Clausus / TMS; отбор по документам и **интервью** (при необходимости — онлайн).
- Документы: заявка, транскрипты, мотивационное письмо, паспорт, сертификат английского.
- Плата за подачу (Medicine): **200 €** (нерефандируемая).

## Актуально для студентов из РФ

- **Виза:** граждане РФ оформляют **национальную студенческую визу** (Studienvisum) в Германии; нужны Zulassung/confirmation letter, финансовые гарантии, страховка. С **01.01.2026** — **биометрический** загранпаспорт для въезда.
- **Финансы:** blocked account (~992 €/мес. — уточнять на сайте посольства) **плюс** подтверждение оплаты/наличия средств на tuition 25 000 €/год.
- **Признание аттестата:** EUC оценивает индивидуально; аттестат РФ + нотариальный перевод на английский; при необходимости — справка об эквивалентности (Anabin / вуз).
- **Approbation в Германии:** диплом **кипрского** EU-вуза; для права на работу врачом в DE — процедура в **Landesärztekammer** (Gleichwertigkeit / Kenntnisprüfung), не прямой Staatsexamen. Немецкий для клиники — планировать заранее.
- **Английский:** для Frankfurt Campus сертификат **обязателен** (исключения для граждан UK/US/AU и др. — по списку EUC; граждане РФ — сдают тест).
- **Платежи:** tuition на счёт EUC FRA Branch (Commerzbank, IBAN DE31700400410280046400) — возможны сложности с переводами из РФ; уточнять у admissions до зачисления.
