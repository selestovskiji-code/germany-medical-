# Freemover — самостоятельная организация

[[index]] · [[02-exchange/|02 — Программы обмена]] · [[exchange-programmes-overview|Обзор программ обмена]]

**Freemover** (Free mover / visiting student) — студент, который **самостоятельно** договаривается о семестре или (чаще для медицины) **клинической практике** в немецком вузе **без** действующего институционального соглашения с домашним вузом и **без** номинации по [[bilateral-agreements|bilateral]] или [[erasmus-plus|Erasmus+]].

## Что это

- Индивидуально организованный стаж / практика / в исключительных случаях — учебный семестр.
- Нет автоматического EU-гранта; нет квоты «партнёрского» обмена.
- Приоритет мест у принимающего вуза — у **номинированных** exchange students; Freemover получает **оставшиеся** capacity.

## Кто может участвовать

| Критерий | Типичное требование |
|----------|---------------------|
| Статус | Зачислен в медвуз дома на весь период стажа |
| Соглашение | **Не требуется** между вузами |
| Семестр обучения | Для **клинической практики** — обычно после определённого курса (зависит от клиники) |
| Семестр курсов | Реже; нужно согласие **обоих** вузов на зачёт ECTS |
| Язык | Для медфаков: **немецкий B2** (Frankfurt рекомендует C1); для отдельных research-стажей — английский |

## Как подать заявку

1. **Согласование с домашним вузом** (деканат / международный отдел): засчитывается ли стаж, нужны ли документы.
2. Выбор немецкого вуза / клиники; поиск контакта клиники или International Office медфака.
3. **Прямое обращение** в отделение (RWTH Aachen) или через портал медфака (Magdeburg, Frankfurt).
4. Пакет документов: мотивация, CV, transcript, рекомендация, прививки, языковой сертификат, **подтверждение клиники** о приёме.
5. Зачисление / регистрация (если требуется) — после подтверждения клиники.

**Не через координатора обмена домашнего вуза** (если только домашний вуз не выдаёт справку для вашего же Freemover).

## Сроки, длительность, финансирование

| Параметр | Примеры |
|----------|---------|
| Клиническая практика (Magdeburg) | До **3 мес.**; окно октябрь–август; заявка с **июля**, рекоменд. до 15.09 на след. уч. год |
| Документы | Не позднее **8 недель** до начала (Magdeburg) |
| RWTH Aachen | Стаж ≥ **2 мес.** в семестре; зачисление как exchange возможно после подтверждения клиники |
| Frankfurt (Medizin) | Семестр / год; дедлайн **15.06** (зимний), **15.12** (летний) |
| Финансирование | **Самофинансирование:** проезд, жильё, страховка, Semesterbeitrag при зачислении; стипендии — отдельный поиск ([[daad-exchange|DAAD]] и др.) |

## Freemover vs Bilateral

| | Freemover | Bilateral |
|---|-----------|-----------|
| Соглашение вузов | Нет | Есть |
| Инициатива | Студент | Координатор + отбор |
| Шанс на клинику | Ниже (остаточные места) | Выше |
| Зачёт ECTS | Индивидуально | Learning Agreement |

## Типичные документы

- Letter of motivation / learning objectives
- Transcript of Records
- Letter of recommendation (профессор / деканат)
- Certificate of enrollment (домашний вуз)
- Proof of immunizations (форма принимающего вуза)
- German B2+ certificate (для клиники)
- **Confirmation from hosting department** (e-mail PDF достаточно, Magdeburg)

## Актуально для студентов из РФ

- **Наиболее реалистичный путь** для студента российского медвуза без действующего [[bilateral-agreements|bilateral]] / [[erasmus-plus|Erasmus+]] — **краткий клинический стаж** (Famulatur-формат), а не полноценный семестр модулей.
- **Геополитика 2022+** не запрещает Freemover **напрямую**, но отдельные клиники / вузы могут **не принимать** заявки или требовать дополнительные согласования — ответ только после индивидуального запроса.
- **Язык:** без **немецкого B2+** шансы на клинику в гос. медфаке низки; английского для повседневной клинической работы обычно недостаточно.
- **Виза:** для стажа >90 дней — национальная виза D; приглашение / подтверждение клиники + справка о зачислении дома; blocked account, мед. страховка.
- **Зачёт в российском медвузе:** заранее письменное согласование с деканатом; Freemover **не гарантирует** автоматический зачёт Famulatur/PJ.
- **Места ограничены** и с низким приоритетом — подавать в **несколько** клиник; начинать поиск за **12+ мес.**
- **DAAD / Erasmus:** Freemover **не даёт** стипендию Erasmus+; DAAD — только при отдельном соответствии программе стипендий ([[daad-exchange|DAAD]]).
