# Двусторонние соглашения (bilateral agreements)

[[index]] · [[02-exchange/|02 — Программы обмена]] · [[exchange-programmes-overview|Обзор программ обмена]]

**Bilateral agreement** (двустороннее / партнёрское соглашение) — прямой договор между **конкретным** вузом (или факультетом) в стране отправления и **конкретным** немецким вузом. В отличие от [[freemover|Freemover]], студент идёт по **институциональному каналу**: отбор → номинация → зачисление как exchange student.

## Что это

- Рамочный договор о обмене студентами (иногда — преподавателями, совместные курсы).
- Может существовать **параллельно** с Erasmus+ или **отдельно** (university-wide partnership, faculty-level MOU).
- Студент остаётся зачисленным в домашнем вузе; диплом домашнего вуза; кредиты — по Learning Agreement.

## Кто может участвовать

| Критерий | Требование |
|----------|------------|
| Вуз | Зачислен в вуз, **являющийся стороной** соглашения |
| Отбор | Внутренний конкурс (GPA, язык, мотивация) — правила домашнего вуза |
| Курс / специальность | По рамкам соглашения (медфак ↔ Medizinische Fakultät) |
| Квота | Ограниченное число мест в год (1–5+ на направление) |
| Язык | Обычно **немецкий B2+** для медицинских курсов |

## Как подать заявку

1. **Международный отдел / деканат** домашнего вуза — список партнёров, дедлайн внутреннего отбора.
2. Подача документов дома (transcript, мотивация, языковой сертификат).
3. После отбора — **номинация** немецкому партнёру (координатор отправляет имя, период, email).
4. Заявка в онлайн-портале принимающего вуза (после номинации — login).
5. **Learning Agreement** — согласование курсов / модулей.

**Напрямую в немецкий вуз без номинации домашнего вуза по bilateral податься нельзя.**

## Сроки, длительность, финансирование

| Параметр | Типичные значения |
|----------|-------------------|
| Длительность | 1 или 2 семестра |
| Tuition | Обычно **нет** дополнительной платы (exchange status) |
| Semesterbeitrag | Может взиматься со стороны принимающего вуза (социальный взнос, билет) |
| Стипендия | Не гарантирована; иногда — вузская / региональная (см. [[daad-exchange|DAAD]], Landesstipendium) |
| Номинация (Mannheim) | 15.03–15.04 (fall), 15.09–15.10 (spring) |
| Заявка после номинации (Mannheim) | 30.04 (fall), 31.10 (spring) |
| Passau | 15.05 (зимний / год), 15.12 (летний) |

## Отличие от Freemover

| | Bilateral | Freemover |
|---|-----------|-----------|
| Соглашение вузов | **Есть** | **Нет** |
| Заявка | Через координатора домашнего вуза | Самостоятельно в принимающий вуз |
| Приоритет мест | Выше | Ниже (остаточные квоты) |
| Learning Agreement | Стандартный для обмена | Индивидуальное согласование |

## Медицинский контекст

- Соглашение часто на уровне **факультета**, не всего университета.
- Клинические блоки (Famulatur, PJ) **не всегда** входят в обмен учебными модулями — уточнять отдельно.
- Координатор Medizinische Fakultät на стороне Германии — ключевой контакт после номинации.

## Актуально для студентов из РФ

- **Универсальное описание:** bilateral работает **только** если (а) ваш медвуз — сторона действующего договора с конкретным немецким вузом, (б) обмен **не приостановлен** политикой одной из сторон.
- **После 2022 г.** многие немецкие университеты **заморозили** сотрудничество с российскими партнёрами (по аналогии с TU Berlin и др.). Наличие MOU на сайте **не гарантирует** приём заявок.
- **Не привязано к конкретным российским вузам в этой заметке** — проверять индивидуально: международный отдел **вашего** медвуза + International Office **целевого** немецкого вуза.
- **Erasmus+ vs bilateral:** соглашение может быть «только bilateral» без EU-финансирования; отсутствие Erasmus-гранта **не отменяет** bilateral, если договор живой.
- **Если bilateral недоступен** — см. [[freemover|Freemover]] (клиническая практика) или отдельные стипендии [[daad-exchange|DAAD]].
- **Виза:** после номинации — letter of admission от немецкого вуза; для граждан РФ — национальная виза D, blocked account, страховка.
