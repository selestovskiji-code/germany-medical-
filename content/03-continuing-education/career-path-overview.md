# Карьерный путь врача в Германии (обзор)

[[index]] · [[03-continuing-education/|03 — Карьерный путь врача]] · [[facharzt-innere-medizin|Facharztausbildung Innere Medizin]]

Краткая схема для **выпускников российских медвузов**, планирующих работать врачом в Германии. Это не пошаговый гайд для практикующих врачей — только карта этапов с отсылками к официальным источникам.

## Схема пути

```
Диплом врача (РФ)
    → Gleichwertigkeitsprüfung (признание / сравнение программы)
    → FSP (Fachsprachprüfung, C1 Medizin) + при необходимости Kenntnisprüfung
    → Approbation (или Berufserlaubnis на переходный период)
    → Assistenzarzt (врач в ординатуре)
    → Facharztausbildung → Facharzt (специалист)
```

## Этапы подробнее

| Этап | Что это | Кто отвечает |
|------|---------|--------------|
| **Gleichwertigkeitsprüfung** | Сравнение иностранного диплома и учебной программы с немецким стандартом (документарная проверка, не экзамен) | Approbationsbehörde выбранной **Bundesland** (земли) |
| **FSP** (Fachsprachprüfung) | Экзамен по **медицинскому немецкому** (~C1): беседа с пациентом, Arztbrief, передача случая коллеге | Landesärztekammer (региональная врачебная палата) |
| **Kenntnisprüfung (KP)** | Устно-практический экзамен по медицине — если программа признана **не полностью** эквивалентной | Approbationsbehörde / по правилам земли |
| **Approbation** | Бессрочная государственная лицензия врача | Approbationsbehörde |
| **Berufserlaubnis** | Временное ограниченное разрешение (часто до 2 лет, под надзором) — пока идёт KP или ожидание Approbation | Approbationsbehörde |
| **Assistenzarzt** | Врач с Approbation в должности **в ординатуре** (Weiterbildungsassistent) | Клиника / Weiterbildungsstätte |
| **Facharztausbildung** | Специализация по правилам **Weiterbildungsordnung** своей Landesärztekammer | См. [[facharzt-innere-medizin|пример: Innere Medizin]] |

## Ключевые экзамены

### FSP (Fachsprachprüfung)

- **Не** проверяет клинические знания как KP — проверяет **безопасную коммуникацию** на немецком в клинике.
- Обычно нужен общий немецкий **B2** до регистрации на FSP; сам FSP ориентирован на **C1** в медицинском контексте (решение министров здравоохранения земель, с 2015 г.).
- Формат и стоимость **различаются по землям** (типично ~60 мин, 3 части, порядка 350–400 €).

### Kenntnisprüfung (KP)

- Назначается, если Gleichwertigkeitsprüfung выявила **существенные отличия** программы, которые нельзя компенсировать опытом работы.
- Устно-практический формат, ориентир — немецкий врачебный экзамен (внутренние болезни, хирургия и др. — по правилам земли).
- Для дипломов из **третьих стран** (в т.ч. РФ) KP назначается **часто**; полное признание без KP — скорее исключение.

## Языковые требования

| Уровень | Назначение |
|---------|------------|
| **B2** (общий немецкий) | Минимум для подачи / в процессе Approbation (сертификат Goethe, telc и т.п.) |
| **C1 Medizin** (FSP) | Обязательный экзамен медицинского немецкого для Approbation |
| Клиническая практика | Даже после FSP — постоянное углубление терминологии и документации |

Курс «C1 Medizin» полезен для подготовки, но **сертификат курса ≠ FSP** — лицензию даёт только сдача Fachsprachprüfung в Ärztekammer.

## Сроки и типичные сложности

- **Gleichwertigkeitsprüfung:** законная ориентировка — до **4 месяцев** после полного пакета документов; на практике сроки часто **дольше** (очереди, дозапросы).
- **Выбор земли:** заявление подаётся в Approbationsbehörde **той земли**, где планируете работать; правила FSP/KP и сроки очередей различаются.
- **Документы:** диплом, приложение с часами предметов, CV на немецком, справки о несудимости, медсправка, при необходимости **Certificate of Good Standing** — всё с **присяжным переводом**.
- **Weiterbildungsordnung** для Facharzt зависит от **Landesärztekammer**, а не от земли Approbation — при выборе клиники сверяйте Weiterbildungsbefugnis.

## Актуально для студентов из РФ

- **Россия = Drittstaat (третья страна):** автоматическое признание по EU-директиве **не применяется**. Путь всегда через **индивидуальное** Anerkennungsverfahren (Gleichwertigkeitsprüfung).
- **Нострификация в российском смысле** здесь = **признание врачебной квалификации (Anerkennung)** в выбранной земле, а не отдельная процедура Минобрнауки РФ. Диплом РФ подаётся в Approbationsbehörde вместе с учебным планом (Modulhandbuch / описание часов по предметам).
- **Kenntnisprüfung:** для выпускников российских программ KP — **типичный**, а не редкий сценарий; закладывайте 1–2 года подготовки после FSP.
- **Пока нет Approbation:** возможна **Berufserlaubnis** после FSP — работа под надзором, часто в той же клинике, где готовятся к KP.
- **Виза:** для подготовки к экзаменам — национальная виза (часто с подтверждением средств); после Approbation — рабочий статус (Blue Card EU / Aufenthaltstitel для Fachkräfte — уточнять по актуальным правилам Auswärtiges Amt).
- **Документы из РФ:** справка о несудимости, Good Standing (через Минздрав / регулятор), нотариальные копии; сроки действия справок часто **3 месяца**.
- **Санкции и переводы:** оплата курсов/экзаменов и переводчиков из РФ может требовать счёта за рубежом; планируйте заранее.
- **Студентам ещё на курсе:** сильный немецкий (B2→C1 Medizin) и стажировки в DE **до выпуска** сокращают разрыв с немецкой программой и облегчают KP; Humanmedizin в Германии на английском (см. раздел 01) **не заменяет** этот путь для диплома РФ.
