# База знаний — медицинское образование в Германии

Структурированная база на **русском языке** для студентов российских медвузов, интересующихся обучением и обменом в Германии, а также кратким обзором карьерного пути врача (Facharztausbildung). Английские названия программ и официальных терминов сохраняются в оригинале.

## Дисклеймер

> **Не является юридической или медицинской консультацией.** Материалы носят информационный характер и отражают состояние на дату проверки (`date_checked`) в каждой заметке. Требования вузов, визовые правила и программы обмена меняются — перед подачей документов сверяйтесь с **официальными первоисточниками** (сайты вузов, DAAD, Auswärtiges Amt, Landesärztekammer и др.).

## Конвенция имён файлов

- **Slug латиницей**, строчные буквы, слова через дефис
- Формат: `название-программы-english-name.md`
- Примеры:
  - `umch-hamburg-human-medicine.md`
  - `erasmus-plus-overview.md`
  - `facharzt-innere-medizin.md`
- **Заголовок** в frontmatter: `title: "Название (English Name)"` — русское название + английское в скобках
- Имя файла **не обязано** дословно повторять title; главное — однозначный slug и соответствие содержанию

## Шаблон заметки

Единый формат frontmatter для всех заметок vault (источник истины для Task 02–05):

```yaml
---
title: "Название (English Name)"
date_checked: YYYY-MM-DD
section: english-programs | exchange | continuing-education
tags:
  - tag1
sources:
  - https://...
---
```

### Поля frontmatter

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `title` | да | Русский заголовок; английское название в скобках |
| `date_checked` | да | Дата последней проверки фактов (YYYY-MM-DD) |
| `section` | да | Раздел vault: `english-programs`, `exchange`, `continuing-education` |
| `tags` | да | Список плоских тегов (см. таблицу выше) |
| `sources` | да | URL официальных первоисточников |

### Рекомендуемая структура тела заметки

1. Краткое описание (1–2 абзаца)
2. Структурированная выжимка (язык, срок, стоимость, требования — по релевантности)
3. **Актуально для студентов из РФ** — отдельный блок с ограничениями и нюансами
4. Ссылки на первоисточники (дублируют `sources` в frontmatter при необходимости)

- В каждой заметке раздела — ссылка обратно на соответствующий MOC или `[[index]]`
